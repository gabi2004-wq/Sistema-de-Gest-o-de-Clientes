# Sistema de Gestão de Clientes

## Sobre o Projeto

O Sistema de Gestão de Clientes é uma aplicação web desenvolvida para facilitar o cadastro, a organização e o gerenciamento de informações de clientes.

O projeto simula uma ferramenta utilizada em empresas para manter dados de clientes organizados e facilitar consultas e atualizações cadastrais.

## Objetivo

Desenvolver uma aplicação prática para gerenciamento de clientes, aplicando conhecimentos de desenvolvimento web, manipulação de dados e armazenamento local.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Funcionalidades

- Cadastro de clientes.
- Registro de nome, telefone, e-mail e endereço.
- Listagem de clientes cadastrados.
- Pesquisa de clientes pelo nome.
- Edição das informações cadastradas.
- Exclusão de clientes.
- Contagem automática de clientes.
- Armazenamento dos dados no navegador.

## Como Executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo index.html em um navegador.
4. Utilize o formulário para cadastrar clientes.

## Armazenamento de Dados

O projeto utiliza LocalStorage para armazenar as informações diretamente no navegador, permitindo que os dados continuem disponíveis após fechar e abrir a página no mesmo navegador.

*Observação:* os dados ficam armazenados localmente no navegador e não são compartilhados entre dispositivos.
